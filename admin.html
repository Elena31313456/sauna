Где взять ключ доступа

Делает тот, у кого аккаунт GitHub с сайтом, один раз.

  1. Откройте github.com/settings/personal-access-tokens/new
  2. Token name: Брони сауна. Expiration: 1 год.
  3. Repository access: Only select repositories → sauna.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Нажмите Generate token и скопируйте ключ.
